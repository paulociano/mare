# 🌊 MARÉ

### Entre de cabeça.

**Doze jogos de palavras. Um mar de possibilidades.**

Uma coleção de desafios em português para quem gosta de descobrir, conectar e brincar com palavras. Tudo em um universo inspirado nas profundezas do oceano.

**[⚓ Içar velas e jogar](https://paulociano.github.io/mare/)**

## Escolha seu rumo

| Jogo | A aventura |
| --- | --- |
| **[Recife](https://paulociano.github.io/mare/recife.html)** | Descubra palavras de cinco letras. Quer ir mais fundo? Alterne entre **Clássico, Dueto e Quarteto**. |
| **[Abismo](https://paulociano.github.io/mare/abismo.html)** | Siga pistas de significado até chegar à palavra secreta. |
| **[Cardume](https://paulociano.github.io/mare/cardume.html)** | Quatro grupos escondidos entre dezesseis palavras. Quem nada junto? |
| **[Corrente](https://paulociano.github.io/mare/corrente.html)** | Encontre letras e sequências para seguir o fluxo até a resposta. |
| **[Concha](https://paulociano.github.io/mare/concha.html)** | Sete letras, uma central obrigatória e muitas palavras para encontrar. |
| **[Trilha](https://paulociano.github.io/mare/trilha.html)** | Ligue letras vizinhas e trace o caminho da palavra. |
| **[Enigma](https://paulociano.github.io/mare/enigma.html)** | Palavras cruzadas para quem gosta de navegar entre pistas. |
| **[Marujo](https://paulociano.github.io/mare/marujo.html)** | Um caça-palavras com descobertas em todas as direções. |
| **[Pérola](https://paulociano.github.io/mare/perola.html)** | Decifre anagramas com pistas em três tentativas. |
| **[Farol](https://paulociano.github.io/mare/farol.html)** | Recoloque as palavras em ordem para reconstruir expressões. |
| **[Náufrago](https://paulociano.github.io/mare/forca.html)** | Descubra a palavra antes de seis erros. |
| **[Sinais](https://paulociano.github.io/mare/criptograma.html)** | Decifre frases a partir de códigos numéricos. |

## Desenvolvimento

Consulte [Arquitetura e convenções](docs/ARCHITECTURE.md) para conhecer a organização do código. Para verificar o repositório use `npm run check` (Node.js 20+).

## Marinheiro de primeira viagem?

Escolha um jogo e comece a explorar. Cada desafio tem suas próprias regras, disponíveis na tela.

Você pode voltar ao convés quando quiser e experimentar outra aventura. Há desafios diários e modos livres em diferentes jogos, com progresso salvo no navegador quando disponível.

## Um oceano para explorar

O MARÉ combina jogos de palavras com uma atmosfera submarina: cenários das profundezas, luzes oceânicas e uma navegação pensada para computador e celular.

Sem cadastro para começar. É só escolher o rumo.
